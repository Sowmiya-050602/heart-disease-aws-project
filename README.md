# Heart Disease Prediction using AWS AI Ecosystem

##  Project Overview
This project is a cloud-based machine learning system that predicts heart disease risk using AWS services and Python.

## Technologies Used
- Python
- XGBoost
- AWS SageMaker
- AWS Lambda
- API Gateway
- DynamoDB
- EC2 (Streamlit)

##  Features
- Real-time prediction system
- Serverless AWS architecture
- Cloud-based ML deployment
- Data storage and logging using DynamoDB
- Interactive Streamlit web application

##  Model Performance
- Accuracy: 73.77%
- AUC Score: 0.8371
